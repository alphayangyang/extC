# 6. 语句

### `for`：四种形态（定案 93）

```extc
for i in i64(0)..n { ... }        // 半开区间：0, 1, ..., n-1
for dy in i64(-2)..i64(3) { ... } // 下界可以是负数
for d in items { ... }            // 容器：视图 / 定长数组 / 字符串（元素是字节）
for (var j: i64 = 0; j < n; j += 1) { ... }   // C-style：三段都是普通语句
```

**生成出来就是 `var` + `while`**：`for i in 0..n { B }` ⇒ `{ var i = 0  while i < n { B  i += 1 } }`
所以它不是新的语句种类，检查器与生成器见到的还是它们本来就认识的东西

三条要记的：

- **范围的类型来自下界** —— `0..n` 里的 `i` 是 `i32`（字面量的默认类型）；要 `i64` 就写
  `i64(0)..n` 比较允许数值加宽，所以 `for i in 0..a.len` 也是合法的（只是索引处多一次转换）
- **容器的元素是拷贝** —— `for d in v { d.x = 1 }` 不会写回 `v` 容器本身先过一遍 `c[..]`
  变成视图，**定长数组因此也能直接迭**（数组自己没有 `.len`，视图才有）
- **容器必须是"可重复求值的位置"**（名字 / 字段 / `*p`）—— 脱糖后的循环每轮都要再读它一次，
  写 `for d in f()` 会在编译期被挡住，并提示先 `var xs = f()`

### 复合赋值 `+=` `-=` `*=` `/=` `%=`（定案 92）

```extc
x += 1        // 就是 `x = x + 1`，右边那条规则与写开的 `x + 1` **同一个函数**判
```

生成的 C **保持复合形式**（`x += 1;` ⇒ 目标只求值一次）。用户自己定义了 `+` 的结构体也行：
`v += w` 变成 `v = vec2_add(&v, w)` 这种情形要求目标里**没有调用**（重写会把目标写两遍），
有调用就报错让你拆成两行。`++` / `--` **故意不做**：一个表达式同时读又写同一个位置，
是未定义行为的老家

```extc
let / var 声明

x = 表达式                       // 赋值（目标是变量或字段）

if 条件 { ... } else if 条件 { ... } else { ... }

while 条件 { ... }

return 表达式
return                           // 无返回值函数

break
continue

{ ... }                          // 裸块，引入作用域
表达式                            // 表达式语句
```

`else` 前面可以换行（不受「换行即语句结束」影响）。

**还没有 `for`** —— 四种形态全部已定案，见第 10 节。
