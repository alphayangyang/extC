7.5 引用：ref 是表达式

ref T（只读）/ mut ref T（可写）都「不可为空、不可做算术」。

ref 在调用点要显式写（定案 10）——让读代码的人一眼看出这里传的是引用不是拷贝：

struct counter {
    n: i32
    fn bump(self: mut ref counter, by: i32) { self.n = self.n + by }   // 会写 ⇒ mut
    fn peek(self: ref counter) -> i32 { return self.n }               // 只读 ⇒ ref
}

fn addTo(c: mut ref counter, by: i32) {     // 自由函数的可写引用参数
    c.bump(by)                              // 方法接收者自动取地址
}

fn main() -> i32 {
    var c: counter = { n: 10 }
    addTo(ref c, 7)                     // ← 必须写 ref
    println(c.peek())                   // 17
    return 0
}

取到哪种引用，由「这个地方可不可写」自动决定（不用你写 mut）：

对什么取引用得到
var 变量mut ref T
let 变量ref T（只读借用随时可以取）
mut ref 参数 / ref 参数跟着参数本身的可写性
var 的字段/元素mut ref T
  • 实参本身就是引用时，不用再写 ref，直接传。
  • let 的变量可以取只读引用（「只是想读一下」），但交不给要写权限的参数： ``extc let c: counter = { n: 1 } println(read(ref c)) // 只读借用 addTo(ref c, 1) // expects mut ref counter, found ref counter ``
  • 只有变量和字段能取引用（ref f() 不行）。
  • ***p：显式解引用（2026-09-20 起不再有隐式解引用**）： - *p 读 = "p 指的那个值"；*p = v 写 = "p 指的那个地方" - p = q 只有"换指向"一个含义 —— = 不用再看右边分辨 - p + 1 / f(p)（要值）/ return p（返回类型是值）⇒ **都要写 *p** - *p 的 p 必须是 mut ref 才能当赋值目标
  • 两个例外（只有这两个）： ① 输出自动解引用 —— 地址不可打印，println(r) 打的就是值 ② 成员选择自动穿透 —— p.field / p.method() 是"导航"，不是"取值"
  • let / var 不带标注 ⇒ 自然类型（引用还是引用）； 想要值的拷贝就写 let v = *p

两条正交的轴（2026-09-20 定案 —— 引用语义最终版）

轴写在哪管什么拷贝时
let / var绑定上（那是"名字"的事）这个名字能不能换绑（p = q）不传染（新名字自己定）
ref T / mut ref T类型里（那是"值"的事）透过它能不能写（*p = v）传染，而且只能变窄（mut ref→ref，反向）

四格（每格一句话）：

只读（透过它不能写）可写（能写穿）
不能换绑let p = ref x ⇒ 得 ref T不存在（"又 let 又 mut"很诡异 ⇒ 报错）
能换绑var p: ref T = ref x（只读游标）var p = ref x ⇒ 得 mut ref T

三条推论： 1. let ⇒ 整条链只读（let p = ref x 自动降级成 ref T；let s = a[..] 同理） 2. 只读权限洗不掉：let p = ref x var q = p *q = 9 ⇒ 拒（权限在类型里 ⇒ 跟着值走） 3. 想写就回源头重新借：var q = ref x（权限从地方取，不是从副本传）

一句话：看不见 mut ⇒ 写不了；看见 let ⇒ 连名字都动不了
let 只锁「名字」，不冻结任何东西（2026-09-20 主人指出）： ``extc var a: i32 = 200 let p = ref a // 只读地借着 a a = 100 // 合法 —— a 自己还是 var println(*p) // 100 ⇒ 引用是「窗口」不是「快照」 ` ⇒ 所以它不叫 const（const 会让人以为 a 被冻住了 而我们没有、也不想有那个能力） ⇒ let = 不可变绑定（跟 Swift 的 let` 同一个意思）
逃逸检查已经做完了 —— 词法深度 depth(r) ≥ depth(v)，今天查四条： 返回 / 局部初始化 / 给字段·元素赋值 / 借来的值不能存进深度 0 的地方。 拿不到指向「活不过自己」的对象的引用 见 §0.5。
