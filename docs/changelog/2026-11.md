## 2026-11-01 · 长表达式链让编译器爆栈：表达式深度预算

**症状** `let x: i64 = 1 + 1 + …`（5000 个操作数写在一行）让编译器自己崩：release 构建 `rc=139`
（SIGSEGV），sanitizer 构建 `AddressSanitizer: stack-overflow`，栈帧在
`checkExprInner`（`src/check/check_expr.c`）→ `checkValue`（`src/check/check_escape.c`）→
`checkExpr` 之间循环。这是合法输入：源码里没有任何嵌套，`a + b + c` 是左结合链，语法深度只有一层；
解析期的 `PARSE_DEPTH_LIMIT`（64）管的是**括号嵌套**，所以这类程序到不了任何现有闸门。而检查、
逃逸分析、层号求解与代码生成都沿 AST 逐层递归 ⇒ 8 MB 栈在 release 约 4000 个操作数处耗尽
（实测 20000 通过、40000 崩；sanitizer 构建约 4000 崩）。

**结构** 检查器加一条深度预算：`Checker.exprDepth` 记录当前表达式走行的深度，上限
`EXPR_DEPTH_LIMIT`（2048），`checkExpr` 每次进入 +1、返回 -1，超限报
`expression too deep to check (the compiler's limit is 2048 levels)` 并返回错误类型。判据取
"合法但不崩"的边界：2048 个操作数的链照旧编译并运行（`tests/sugar/sugar_long_chain.extc`，1500 项求和），
2049 起拒绝（`tests/errors/expr_chain_too_deep.extc`）。上限取值与 `PARSE_DEPTH_LIMIT` 同类，理由写在
`src/check/check_expr.c` 的常量注释里：sanitizer 构建在 2048 层仍留约一倍栈余量（实测 3500 通过、
4000 崩）。用户可见的口径补进 `docs/usage/language.md` §12 的"现在写不出来的写法"表。

**判据** `tests/run.sh` 376/0（新增反例进全局拒绝语料）；`tests/sugar/run.sh` 29/0（新增正例与反例各一条）；
sanitizer 构建对 5000 项链给出一行诊断而不再 `DEADLYSIGNAL`；`&`、`|`、`*`、`&&`、移位、调用与下标
混合的 5000 项链同样只出诊断（不再有哪一类运算符走别的递归路径）。
## 2026-11-01 · 判据不许依赖注释措辞：注入锚点、默认值断言与 ownSlab 副本

**症状** 整仓注释英文化（同一批"现在写不出来的写法"条目之上）让 `check.sh nobench` 从 130/2/0
掉到 125/2/7，三处红都不是代码坏了，而是**判据盯的是注释文字**：`tools/inject.py` 的 12 处注入锚点
是逐字匹配源码，注释一改全部失配；`tests/reclaim-perf/gate-rt-defaults.sh` 用中文正则
`默认 \`VAR=值\`` 抓运行期注释里"声称的默认值"，译文只有 "`VAR=值` is the default"，一条也抓不到，
判据自己报"注释措辞变了"；`tools/check_ownslab_body.py` 要求两份 `extc_rc_ownSlab` /
`extc_rc_ownSlabMark` 体逐字相同，译文在一份里留了 `;`、另一份用了 `,`。

**结构** 判据与注释解耦，三处各按自己的口径修：`inject.py` 新增 `strip_c_comments`（逐字符扫掉
`/* … */` 与 `//`，**不区分**落在 C 代码还是发射文本的字面量里）、`anchor_spans`（去注释后匹配、再映射
回原文区间）、`apply_patch`（命中恰好一次才替换），`check_anchors`/预检/打补丁三处都改用它们；
`shade-noinval` 的锚点因为去注释后只剩一行 `extc_rc_shadeNextGen();`（文件里出现四次）扩成三行
（`freed++` / `}` / 目标行）。`gate-rt-defaults.sh` 的 `claimed()` 同时认英文 "`VAR=值` is the default"
与旧中文写法，保留末尾 `[ "$n" -gt 0 ]` 的防空转守卫 —— 判据仍要求"注释声称的默认值与产物 `#define` 相同"，
只是不挑语言。`ownSlab` 两份体的标点统一成 `;`。

**判据** `python3 tools/inject.py --check-anchors` → ok（32 条注入、41 处原文各命中一次，且 `old != new`）；
`tests/reclaim-perf/gate-rt-defaults.sh` → 通过 1、失败 0（`EXTC_RC_NOCOUNT` 声称 1、`#define` 也是 1）；
`tools/check_ownslab_body.py` → ok；`check.sh nobench -j8` → 132/2/0（`gate-reclaim-ledger` 在 -j8 下
约 56 s，单独跑 52 s 通过：并行负载下会慢，不重试不影响结论）。
