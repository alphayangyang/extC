# 现在有什么 / 怎么用

本目录只写**两件事**：现在有什么、怎么用。**不写历史**（历史只进 [`../CHANGELOG.md`](../CHANGELOG.md)），
也不写待做（待做只进 [`../TODO.md`](../TODO.md)）。

页面清单（**待写**的页面在 [`../TODO.md`](../TODO.md) 第七节里挂着）：

| 页面 | 内容 |
|---|---|
| `00-start.md` | 构建 · 跑测试 · 验收 · 编译器开关 |
| `language.md` | 语言现状：词法、类型、语句、内存模型、错误与逃生舱 |
| `stdlib.md` | 标准库现状 |
| `modules-cabi.md` | 模块与 C 互操作 |
| `internals.md` | 编译器内部结构（现状） |

**写作规矩**：每一句都要能被**源码位置**或**一条能跑的判据**支撑；例子用 `@code` 或代码块，
且必须能被闸门检查。
