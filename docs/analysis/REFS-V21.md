## 5. 使用规则（与 v19 文档相同，逐条仍然有效）

1. 引用旧行号前先查 §2 的等值段；落在变更块里的行号按 §3 做**语义复核**，禁止机械偏移重指（R1 曾因此把 `thrUpd` 指到 `markResume`）。
2. 块内引用按 `grep -n` 重锚，不按偏移推算。
3. 文档行号必须带版本口径（例：「`reclaim.c:3334`（v21）」）。
4. 只有 `reclaim.c` 变了；`codegen.c`/`driver.c` 的行号继续按 v18 口径使用。
5. `tests/gc-p0/bseg-cal.tsv` 的行绑定 `src_md5`（reclaim.c + codegen.c）与 `extc_md5`；换构建必须重标，否则门禁告警「标定行陈旧」。
6. **走步循环（mark/sweep 的 pop 与 scan）里不许读时钟**：`[work]` 的三跑逐字相同是项目唯一可靠的窗口判据（`tests/reclaim-perf/gate-work.py`），按时间切步会破坏它。这条由 `tools/check_mark_batch.py` 的两条断言（`batch walk reads no clock`、`shallow drain reads no clock`）与注入自测守着。
