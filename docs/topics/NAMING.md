# 命名与注释规范（V 批次）

> 这份文件是**词的纪律**与**注释的义务**的唯一权威。它来自实际付出代价的地方：
> R1/R3 批次里 13 条 bug 有 12 条长在"同一个事实被两个入口/两种拼写表达"的接缝上，
> 而 U/V 批次的接口统一、阶段契约、断言化都是为了让它不再复发。

## 1. 词的纪律（一个词只能指一件事）

| 词 | 只能指 | 不许指 | 备注 |
|---|---|---|---|
| `depth` | **深度**：`0` = 活得最久（全局、参数所指、调用者选的地方），**数越小活得越久** | 不许单独用 —— 必须带限定词（见下三条） | 极性见 `check_internal.h` 的"极性契约" |
| `slotDepth` | "**存的地方**有多深"（`a`、`a.f`、`a[i]` 这些地方本身的寿命） | 不许指"它指向的东西" | 旧名 `placeDepth` |
| `targetDepth` | "**值指向的东西**有多深"（`p`、`f(x)` 的结果） | 不许指存储槽本身 | 旧名 `exprRefDepth` / `exprRefDepthPure` |
| `solvedDepth` | 电平求解**稳定之后**重算出来的深度 | 不许指"当场算的那次" | 旧名 `solvedValDepth` |
| `level` | arena/zone 的**层级号**（`ARENA_HOME`/`ZONE_HOME` 是特殊值，不是层号） | 不许与 `depth` 混用 | `storeLayer` 答的是"存的地方在哪一层" |
| `place` | **可写的地方**：绑定、字段、元素、切片 | 不许指"值" | |
| `slot` | 绑定的**存储槽**（与"槽里的值指向什么"区分） | 不许指身份 | |
| `binding` / `Sym` | **身份**（哪个绑定），与拼写无关 | 不许用 `name` 冒充 | 见第 3 节 |
| `name` | **拼写**（源码里写的字符串） | 不许当身份用 | 需要身份时用 `binding` |
| `root` | 根遍历的**终点表达式**（`extcRootLeaf` 返回 `EX_IDENT`） | 不许指"根绑定"（那叫 binding） | |
| `publish` / `note` | **发布一个事实**（`noteStore`、`noteReturnPublish`） | | |
| `invalidate` / `drop` | **让一个事实失效**（`unNarrow`、`freshDrop`） | 不许与 publish 混 | 写点必须成对：发布 + 失效 |
| `TODO(名)` | 只用于**有主人**的待办；无主的观察写成 `[note]` 或记录文件 | | |

## 2. 注释的义务（非显然的代码必须回答）

1. **回答哪个问题**：是"存储深度"还是"所指深度"？（三个 `*Depth` 的分工见第 1 节。）
2. **极性契约**：这个数/标志里"大"与"小"、"真"与"假"各表示什么？兜底落在哪一侧？
   `0` 一律不许兼两义（R1/R3 的 P0-2 就是它）。
3. **证据**：非显然的选择要带**实测**——数字、反例、判据在哪（`tests/…`、`tools/gate_*.py`）。
   本仓库的好风格是"注释里带测量值"，例如 `pools.c` 里 memset 那段的 −3.7%/−17.7%。
4. **历史**：这条规则是被哪个 bug / 定案换来的？（写 `P0-x` 或定案号，方便追溯。）
5. **阶段**：只在某个阶段合法的东西，要写明（见 `check_internal.h` 的"阶段契约"）。

## 3. 身份 vs 拼写（最贵的一条教训）

参数遮蔽是**合法语言特性**（`examples/shadowing.extc`），所以：

* 一切"这个值来自哪个参数/哪个绑定"必须按**符号身份**（`paramIndexOfExpr`、
  `identBindOf`、`FuncDef.paramSyms`）；
* 只有在调用点**手上确实只有名字**时才用 `paramIndexByName` —— 它的注释里写了这条限制；
* **阶段契约**：所有函数体检查完之后（`PHASE_POST`）**没有作用域**，`lookup`/`placeRoot`
  这时只能解析到**模块级绑定**。实测：套件里 POST 阶段有大量 `lookup("self")` 这类**局部**名字
  ⇒ 只能得到 `NULL` 或同名全局。所以 POST 阶段的身份必须来自记在节点/符号上的信息。

## 4. 改名对照表（V2/A1）

| 旧名 | 新名 | 为什么 |
|---|---|---|
| `placeDepth` | `slotDepth` | "地方有多深"与"值指向的东西有多深"过去同名，读代码易串 |
| `exprRefDepth` / `exprRefDepthPure` | `targetDepth` / `targetDepthPure` | 同上 |
| `solvedValDepth` | `solvedDepth` | 它是"电平稳定后重算"的那一个，与当场算的区分开 |

**历史记录不改**：`docs/reviews/COMPILER-AUDIT-2026-09-30.md` 与 `.audit/*-LOG.md` 是**带日期的
记账**，里面的旧名保留原样（当时的代码就叫那个名字）—— 对照表在这里，读历史时查这一节。
