# 按需发射（worklist）实施方案（2026-10-05）

> 第 1 步的施工方案。目标：**在发射之前决定"谁存在"**，让生成的 C 里不可能有死代码。
> 前提与验收数据见 `CODEGEN-ARCH.md`（附录二 + E1 实测）。**动手前先回答文末"必须先回答的问题"。**

## 一、为什么这一步是纯重构（这就是"零回退"的底气）

死代码**今天已经被删掉了**（M1：6917 个 static 函数，0 个没人调用 ✓）。
所以按需发射**不改变可观测输出** ⇒ **414 份产物指纹应当逐字节不变** ✓✓
⇒ 每一步都能用一个 `diff` 判生死，不需要"跑跑看" ✗。

**收益在别处**：文本扫描层退场（成本不再随产物规模增长）、`need*` 旗子退休、发射顺序不再决定事实。

## 二、发射的现状：三类东西，三种"谁存在"的判定

| 类别 | 今天怎么决定 | 目标 |
|---|---|---|
| **函数/泛型实例/原型** | **先全发**，之后由 `dropUnreferenced` 的函数段按 `countGet(name) != 2` 删 | 需求闭包 |
| **描述符行** | 已经是半按需的（`descRef` 发号；`SCALAR_DESC` 行"发了再删"）✓ | 收进闭包 |
| **运行时块/原语** | 15 个 `need*` 旗子（**发射途中顺带置位** ⇒ 顺序敏感 ✗） | 收进闭包 |
| **函数体内的局部/载荷绑定** | `dropUnusedLocals`（**在活函数内部**，按需发射帮不上 ✗） | **本轮不动**（另立项）|

## 三、worklist 的形状

```
起点集合 S0 = { main, @export 的函数, 模块 init 入口, 被驱动的入口 }
worklist W = S0
while W 非空:
    e = W.pop()
    if e 已发射: continue
    发射 e（原型 + 定义 / 描述符行 / 运行时片段）
    在这次发射**过程中**记录它引用的实体 ⇒ 全部推入 W
```

**关键性质**：发射某个实体**只依赖名字**，不依赖别的实体的文本 ⇒ 可以按任意顺序发射 ✓
（这正是现在做不到的地方：现在的删除判定依赖"整篇文本"✗）。

**闭包要覆盖的引用边**（每一条都要在发射时登记）：
函数/方法调用 · 泛型实例引用 · 描述符（含**嵌套字段类型**的描述符 ✓ 递归）· 运行时原语 ·
运行时**块**（块 ⇐ 它的任一原语/片段被引用 ✓ 这正是替换旗子的地方）· 模块级全局与其 init。

## 四、子步（每步都有判生死的数据）

| 步 | 做什么 | 期望指纹 | 期望 M1 | 可回退性 |
|---|---|---|---|---|
| **W0** | **只加仪表**：数出"今天删除 pass 实际删了多少个实体"（函数/描述符/原语各多少），并把它挂到现有调试开关（`EXTC_DBG_PRIM` 同族） | **不变** ✓ | 0 | 无风险（只加计数）|
| **W1** | **登记 API**：发射实体时就地登记 `{name, kind, block, span}`；删除端**优先用登记信息**，行形识别降级为兜底 | **不变** ✓ | 0 | 小（双路径并存 ⇒ 可对照）|
| **W2** | **worklist**：加需求闭包；**先只对"运行时块"生效**（替换 15 个旗子） | 只在旗子判错的产物上变（预期：**仅 BG-1 那类**）| 0 | 中（可开关切换回旗子）|
| **W3** | worklist 覆盖**函数/实例/描述符** ⇒ 删除 pass 的函数段与描述符段**退场** | **应当不变** ✓（因为今天它们删掉的正是这些）| 0 | 中 |
| **W4** | 删掉 `dropRuntimeDefs` 的行形识别与 anchor 技巧（保留 `dropUnusedLocals`） | **不变** ✓ | 0 | 小 |

**每一步的判据是同一个三元组**：`指纹 diff` + `M1 计数` + `gcc -O2 时间/字节`（M2 的两个数）✓。

## 五、回退最小化的两个手法

1. **旧机制当"预言机"**：W2/W3 期间**保留**删除 pass，但把它的删除次数**打印出来**。
   如果按需发射真的做对了，删除次数会**掉到 0** ✓ ⇒ "新机制是否生效"变成一个**可观测的数字**，
   而不是靠赌 ✓✓（这是本方案最重要的设计：**让新机制通过旧机制的"闲置"来自证**）。
2. **双路径并存 + 开关**：W1/W2 都保留旧路径，用编译期开关切换；任一步指纹不符 ⇒ 单个开关回退 ✓。
