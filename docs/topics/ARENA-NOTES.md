## 1 没做成、但方向已经清楚的两件事

### 1.1 路径敏感的 arena 选择（「下沉」）

**问题**：同一个 `new` 站点，走不同分支时"这一次真正需要活到哪一层"可能不同；
现在按**最坏那条路径**定案 ⇒ 别的路径陪着多占内存。

**实测靶子**：200 万轮下，只读不外存 **1.6 MB** vs 多一条外存分支 **33.2 MB**。

**落地形态**（原型里跑通过）：检查期维护一条**分支条件栈**，存储时把"这次存储的目的地层"
与"夹在分配点与存储点之间的那个条件"记到分配点上；codegen 吐
`(*(cond ? &__extc_a[shallow] : &__extc_a[deep]))` ⇒ 走别的分支时对象住得更深、回收更早 ✓

**三条必须的护栏**（每条都是被实测逼出来的）：
1. 备用层必须落在合法区间里，越界**一律退回单层**（越界写比不优化危险得多）；
2. 条件必须**可重复求值**（三元在 C 里会求值两次）；
3. 条件所在的作用域必须**严格比分配点更外** —— 同层"声明在使用之后"也查得到，
   否则生成的 C 会 `undeclared` ✗。

**为什么没落地**：机制通、判据错了 5 次 ⇒ 停手。方向铁律：新机制**只许把层放深，绝不许放浅**
（放浅需要整个新的证明）✓

### 1.2 两层尝试：把"层号"从"边查边拍板"改成"按照约束解算"

**已经落地的部分**（这一版是好的）：分配站点的层号由**一张事实表**重放到不动点而定，
而不是"见到 `new` 就先定一个层"。实测：长运行形状 **98 MB → 50.8 MB**（= 容器自己内联写
那条目标线，一分不差）✓

**还没做成的部分**：把"容器里某一格装的东西活到哪一层"也纳入解算 ——
聚合类型的字段表**参与了记数**，但**没有参与传播**：
`var h: box = { p: null, q: null }` 之后 `h.q = x` 的来路只在字段表里，
而顺着 `out = h` 想给 `x` 降层号时，沿 `Sym.origin`（只记声明时的初始化式）**追不到它** ✗

**教训（值得记住的形状）**：`promoteInto` 有**两个身份** ——
"提升"和"记事实"。它的每一处**提前返回**都只对前者成立 ⇒
凡是"往外存必须经过的地方"都不许提前返回，要么记完再退，要么退之前先递归 ✓

## 2 仍然有效的判据（别删，删了就会重犯）

1. **层号与深度必须同数**：`refDepth` 与 `arenaLevel` 是同一个事实的两种说法
   （`ARENA_HOME ⇒ 0`）。只在某个条件分支里更新其中一个，另一个就会漂 ——
   这一条已经做成自检：`EXTC_SELFCHECK=1 ./build/extc <file>` ✓
2. **"两把尺子一起看"**：改这一层时，每次都要同时跑 `tests/run.sh`（期望 255/0）
   **和** `tests/arena-promoted/run.sh`（期望 22/22 + ASan 干净）。
   出现过"转正库 18→20 而主套件 255→253"的**假进步** ✗
3. **哨兵不许动**：`tests/errors/generic_return_local.extc` 必须**仍然被拒**，
   反例库 `H1_strongupdate_missed` 必须**仍然 REJECT** ——
   它们是"什么都放宽"的守卫，历史上都抓到过"绿的但是假的" ✓
4. **只改注释的改动也要有判据**：`tools/comment_neutral.py`（剥掉注释逐字节比代码）✓

## 3 环境与流程坑（当时浪费了好几轮，记下来）

- **宿主路径**：WSL 的 UNC 路径（`\\wsl.localhost\…`）+ 目录会让工具把 `.git` 当文件
  realpath ⇒ `EISDIR` ⇒ 会话重置。绕法：用一个不含 `.git` 的镜像目录，或修工具 ✓
- **`/tmp` 是 tmpfs**：会话一崩就清空 ⇒ 试错用的程序放**仓库内**（`build/tmp/`）✓
- **`make clean` 会 `rm -rf build/`** ⇒ 放在 `build/tmp/` 下的 git worktree 会被一起删掉 ⚠️
- **别用大段 heredoc 重写整个文件**：这个仓库被批量替换弄坏过 4 次 ✗
  改源码用小步替换（`edit`，或 Python 里 `assert old in s` 之后替换）✓
- **`.o` 逐字节相同不能当"只改了注释"的判据**：注释行数一变，调试行号表就变 ⇒
  要看**剥掉注释之后的代码文本**（`tools/comment_neutral.py`）✓
- **gdb 优先于 print**：`build/extc` 自带 `-g`，断点要按符号名/行号**过滤**（否则 prelude
  的几百次调用淹掉输出）、`%d` 要配 `(int)` 强转（否则 gdb **静默失效**）、
  断点行要选**变量已赋值的那一行**；`watch -l e->refDepth` 能一次答出"谁改的" ✓
- **一次只改一处、改完立刻跑两把尺子**：把"改源 + make + 跑测试"塞进同一次调用时，
  崩了分不清是哪一步 ✗
