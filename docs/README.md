# docs 索引

本仓库的文档只有**三类内容**：

| 类别 | 位置 |
|---|---|
| **现在有什么 / 怎么用** | [`usage/`](usage/) |
| **有什么待做** | [`TODO.md`](TODO.md) |
| **开发历史（全仓库唯一）** | [`CHANGELOG.md`](CHANGELOG.md) |

历史快照（只作考古，**不要当现状读**）：[`archive/`](archive/README.md)

## 维护规则

1. **文档不写历史。** 不写"以前是 X、现在改成 Y"，不写决策编号（`定案 NN` / `PLAN #NN`），
   不写实测史与回退史。**历史只进 `CHANGELOG.md`。**
2. **`TODO.md` 的生命周期**：条目**做完 → 搬进 `usage/`（或者舍弃）**；**砍掉 → 直接删除**
   （不留"已取消"、不留删除线）。
3. **每一句都要能被支撑**：要么指向源码位置，要么配一条能跑的判据。**没有支撑的话不写。**
4. **注释用 Doxygen**：`@brief` / `@param` / `@return` / `@code`；说明、参数、返回值、使用例。
   函数体内只留**不显然的不变量**。规范见 [`COMMENT-STYLE.md`](COMMENT-STYLE.md)。
5. **`@code` 里的例子要能被闸门检查**（extC 示例编译并运行；C 示例至少 `-fsyntax-only`）——
   否则例子会先烂。
