extC 打印格式真值表（描述表换线**必须逐字节对齐**的东西）
生成方式：./build/extc --run <下列用例>（2026-09-21 实测，逐字复制输出）

标量: 42 3.5 true                       ← i32/f64/bool 直印
字符串字面量: hello                     ← slice<u8> 按**文本**印（不带引号）
结构体(含嵌套/切片/数组/?ref): inner { x: 5, y: true }
外层结构体: outer { a: 1, b: 2, f: 0.5, s: hi, in: inner { x: 5, y: true }, xs: [1, 2, 3], arr: [7, 8], np: <ref> }
对照结构体: inner { x: 0, y: false }
枚举无载荷: red blue                    ← 只印**变体名**
枚举带载荷: circle rect nothing          ← ⚠️ **载荷被丢掉了**（circle(2.5) 只印 circle）
泛型枚举: hold2 empty2                  ← 同上，载荷丢掉
option: some none                       ← ⚠️ 同上（some(3) 只印 some）
result: success failure                 ← 同上
切片: [1, 2, 3]
嵌套数组: [[1, 2, 3], [1, 2, 3]]
结构体切片: [inner { x: 5, y: true }, inner { x: 5, y: true }]

规则归纳（给描述表用）：
  · struct  → `名字 { 字段名: 值, … }`（空结构体是 `名字 {  }`）递归 ✓
  · 切片/数组 → `[a, b, c]`（分隔 ", "）✓
  · 枚举（含 option/result）→ **只印变体名，载荷不印** ✗
  · ?ref → `<ref>`（非空）/ 待确认空值（见下）
  · slice<u8> → 按文本印（它跟其它切片的规则**不一样** ✗）

⚠️ 两个待拍板/待确认：
  ① 载荷被丢掉：是**有意**（只看 tag）还是**漏了**？描述表方案要决定是否顺便补上
     （补上会**改变输出** ⇒ 撞'逐字节不变'的判据，需要主人点头）
  ② 空 ?ref（null）印什么？本用例只覆盖了非空 ⇒ 换线前要补一个用例抠出来
