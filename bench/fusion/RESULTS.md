# bench/fusion —— 元素链融合（S1/S3）实测

> 本文件由 `bash bench/fusion/run.sh` 的实测输出抄录（该脚本没有生成器，报告格式与
> `bench/par` 保持一致）；口径见 `SPEC.md`。

## 机器与口径

| 项 | 值 |
|---|---|
| CPU | `Intel(R) Core(TM) Ultra 9 275HX` |
| 内核 | `Linux 6.18.54.1-microsoft-standard-WSL2` |
| nproc | `24` |
| C 编译器 | `cc (Ubuntu 15.2.0-16ubuntu1) 15.2.0` |
| extC 前端 | `./build/extc` |
| 钉核（taskset） | `6` |
| RUNS（取中位数） | `5` |
| n | `1048576`（a/res/tmpv/tv2 各 8 MiB f64） |
| iters | `8` |
| 旗子 | `cc -O2 -std=c11 -fwrapv`；extC 两臂同一份源码，差别只有 `--no-fuse` |

## 结果

| 形状 | 臂 | 中位 ms | 相对未融合 | 相对手写 | cs |
|---|---|---:|---:|---:|---:|
| S1 | 融合（默认） | 19.048 | **0.496×（快 2.02×）** | 0.980× | 1017735235 |
| S1 | 未融合（`--no-fuse`） | 38.404 | 1.000× | 1.976× | 1017735235 |
| S1 | 手写融合（C） | 19.439 | — | 1.000× | 1017735235 |
| S3 | 融合（默认） | 11.858 | **0.154×（快 6.5×）** | 0.947× | 8141881882 |
| S3 | 未融合（`--no-fuse`） | 77.154 | 1.000× | 6.158× | 8141881882 |
| S3 | 手写融合（C） | 12.528 | — | 1.000× | 8141881882 |

同形状三臂 `cs` 相同 ⇒ 做的是同一份工作；融合臂的生成 C 里没有临时视图（脚本断言）。
两条判据都满足（S1 ≥ 1.3×，S3 ≥ 2×），且编译器融合与手肉融合相差 ~2–5%（同档内）。
S3 的 6.5× 来自三处一起去掉：两层临时视图的写+读共四趟内存流量，换成一趟读 `a` 加累加。
